A tiny deterministic Python program that writes one deadpan robot-vacuum alibi — a single line of at most 200 characters — to /output/entry.txt. The vacuum insists the missed spot was a protected dust-bunny habitat whose disturbance would void its warranty.

## Run it

```sh
python3 main.py
```
